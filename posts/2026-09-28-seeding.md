### Being random is expensive, and usually not that important... (casinos etc) 

But you can sort of simulate randomness by using complex math. Randomness is really just a word we use when two things are unrelated or unpredictable in context. The pattern that *prngs* (pseudo-random number generators) produce is too complicated to be recognized, so it feels random. The same could be said about true random, but on a much larger scale, i.e. no human or computer can predict the pattern.

### Seeding Randomness

A **seed** is the starting point of this psuedo random function, which continues to get complicated, and ends up in a different (same) place depending on the start. You’re setting the start of a path.

## Exporting L5 Projects

You have several options for sharing your L5 project:

1. You can export a .love file that anyone with LOVE installed on their computer can open (EASIEST)
2. You can build a web application that will run in a browser, using a 3rd party tool. There are a few restrictions such as more limited sound options. And displaying your code sketch in a browser may not render well on phones/tablets. (MEDIUM DIFFICULTY)
3. You can create an executable application for Mac and for Windows. In both cases you will need to combine your .love file with a copy of the LOVE application for the operating system you are targeting, and make some manual file changes. (ADVANCED)

### Creating a .love file to distribute your project

Since L5 uses the LOVE library under the hood you can export your project as a .love file and anyone with LOVE installed can run it.
